# Paisa – offline money tracker
Static PWA. No backend, no database; data lives in your browser's localStorage.

## Deploy
1. Push this folder to a GitHub repo.
2. vercel.com → Add New → Project → import the repo → Deploy (no build settings needed).
3. Open the Vercel URL on your phone once (with internet).

## Install on phone
- Android Chrome: ⋮ menu → Install app / Add to Home screen.
- iPhone Safari: Share → Add to Home Screen.

After the first load it works fully offline. Use Backup regularly: clearing browser data erases your records.
